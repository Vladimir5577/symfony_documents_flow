## Грабли окружения, найденные этой ночью

- **Фоновая задача bash-тула меняет рабочий каталог сессии.** Команда с `cd`
  внутри фоновой задачи оставила сессию в `analytics_platform`, хотя тул
  сообщил обратное. Следующий `git archive HEAD` собрал не тот репозиторий.
  Лечение: в каждой команде указывать репозиторий явно (`git -C <путь>`).
- **Git Bash подменяет пути в аргументах `docker`.** `docker cp file
  container:/tmp/x.sh` превращается в `container:C:/Users/.../x.sh`, файл
  уезжает не туда, а `docker exec` падает с «No such file or directory».
  Лечение: вызывать `docker` из PowerShell (совпадает с граблями из плана про
  `-w /app`).
- **PowerShell ломает кавычки в длинных `bash -lc`.** Скрипты для контейнера
  писать файлом и заливать через `docker cp`, а не инлайном.
